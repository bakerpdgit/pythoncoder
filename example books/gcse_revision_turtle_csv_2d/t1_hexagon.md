# Turtle 1: Fix the hexagon

**Level: trivial - fix the errors**

This program should draw a **filled orange regular hexagon** with sides of 80 pixels, starting from the centre of the screen and turning **left** at each corner. It should look like this:

![preview](turtlepreview)

The code in the editor contains **5 errors**. Four of them stop the program from running (or crash it). The fifth is a **logic error**: the program runs without any error message, but the picture is wrong.

## What to do

Run the program, read the error message, fix that line, then run it again. Repeat until the hexagon appears correctly filled in orange. Only change what is wrong - don't rewrite the program.

## Hints

Error messages tell you the line number. Check spelling and capital letters carefully - Python is case-sensitive, so `Turtle` and `turtle` are different names.

A subprogram is only called when it is followed by brackets, even when it takes no parameters.

## Checking your work

Your hexagon should match the picture above exactly: orange, filled, and drawn with left turns.
