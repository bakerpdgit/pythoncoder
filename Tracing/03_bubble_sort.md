# Bubble sort

Bubble sort introduces nested loops and list mutation. Each comparison examines neighbouring items. When they are in the wrong order, the three assignments swap them.

Watch:

- `pass_number` — which outer pass is running
- `index` — the left-hand position of the comparison
- `numbers` — the list after a swap
- `temporary` — the value held while the swap takes place

Use **Expand** beneath the `numbers` heading to see the list contents. A new outer-loop iteration creates a clear boundary in Compact mode.
