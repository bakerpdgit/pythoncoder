# A running total

This first example traces a single `for` loop. The loop visits each of the five numbers and adds it to `total`.

Run the program in **Trace** mode and watch these columns:

- `number` — the current item selected from the list
- `total` — the accumulated value after the assignment

The loop starts a new trace-table row for each iteration. Notice that cells remain blank on rows where that variable was not assigned.

The values assigned to `total` are `4`, `11`, `13`, `19`, and finally `22`.
