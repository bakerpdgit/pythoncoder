# Task: two days on one chart

Draw this chart of two days' temperatures:

![preview](chartpreview)

| Part | Detail |
| --- | --- |
| Monday | a line with a dot at each reading (`marker="o"`), labelled `"Monday"` |
| Tuesday | a **dashed** line with no dots, labelled `"Tuesday"` |
| Title | `Temperature through the day` |
| x axis | `Hour` |
| y axis | `Degrees Celsius` |
| Legend | showing both labels |

The first `plt.plot` is started for you. Page 19's table of arguments has
everything else.

## How it is marked

Your chart is compared with the expected one: the title, the axis labels, the
legend, and each line's label, numbers, dots and dashes. Colours and sizes are not
checked. If something differs, the results say what, and show both charts.
