# Task: reaction times

Ten people pressed a button as soon as a light came on. Their times, in
milliseconds, are in `times`, in the same order as `names`.

Replace each `____`:

| Line | Should hold |
| --- | --- |
| `average` | the mean time |
| `middle` | the median time |
| `spread` | the standard deviation |
| `fastest` | the **name** of the fastest person |
| `slowest` | the **name** of the slowest person |

For the last two, `names[____]` needs a *position*. Page 3 showed which method gives
the position of the smallest or largest value rather than the value itself.
